# Archived Research Artifacts

This directory contains reference and presentation artifacts that are not part
of the active computational pipeline. Do not inspect or use them unless the
user explicitly requests archived material or directs the work here.

## Layout

- `documents/`: PDF, Word, and similar document artifacts.
- `tables/`: CSV, spreadsheet, and similar tabular artifacts.
- `images/`: PNG, JPEG, SVG, and similar image artifacts.

Keep new standalone artifacts grouped by type. Experiment outputs that belong
with manifests or derived tables should remain inside their experiment output
directory.
