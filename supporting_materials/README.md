# Supporting Materials

Materials in this directory are relevant cross-project references copied into
`equatorial` for local availability. They are not replacements for their
original files elsewhere in the dissertation workspace.

- `network_decomposition/`: network-layer decomposition scheme, source code,
  mathematical description, and article reference.
- `lbr_era5_grid_coverage/`: frozen ERA5 coverage/precipitation data and its
  self-contained renderer.
- `LBR_FIGURE_PROVENANCE.md`: protected locations for the LBR ERA5 and
  crop/cluster/road/destination figure families, including code and data.
